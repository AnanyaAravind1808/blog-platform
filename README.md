# 📝 BlogPlatform

A full-stack blog platform built using **React, Vite, Node.js, Express, and MongoDB**.

The application allows users to register, log in, create and manage blog posts, add comments, search posts, and interact with blog content.

## 🌐 Live Demo

🔗 **Live Demo:** https://blog-platform-dhum.vercel.app

- **Backend:** https://blog-platform-one-ruby.vercel.app

## 🚀 Features

- 👤 User Registration and Login
- 🔐 JWT Authentication
- 📝 Create, Edit, and Delete Blog Posts
- 💬 Comments
- 🔎 Search Posts
- 🏷️ Category Filtering
- 👨‍💼 Admin Dashboard
- 👥 User Management
- 📊 Admin Statistics
- 🛡️ Role-Based Access Control
- 🌐 RESTful API
